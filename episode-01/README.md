# Город слепых — серия 01 «Дом 17»

Самостоятельная первая серия вертикального мистического сериала. Курьер Марк получает посылку на несуществующий адрес и впервые поднимает повязку. Доставку он завершает, но звонок исчезнувшей матери открывает новую опасность.

- Вертикальный MP4, 1080×1920, 30 кадров/с, примерно 102 секунды.
- Голос: Microsoft Edge-TTS `ru-RU-DmitryNeural`, rate +33%, естественная высота; дополнительное ускорение 1,16× без изменения высоты.
- Пословные субтитры получены из временных меток TTS.
- Фотореалистичные изображения сгенерированы для серии. Движение камеры, дождь, предметы, сообщения, карта и звонок анимированы в Remotion. Это анимационный монтаж изображений и графики.
- Музыка и звуковые эффекты синтезированы программно для проекта.
- Хук: «В моём городе за открытые глаза забирают навсегда».
- Клиффхэнгер: «Не верь ребёнку. Он уже стоит за тобой».

Видео: [`../videos/gorod-slepyh-episode-01.mp4`](../videos/gorod-slepyh-episode-01.mp4).

План сезона: [SEASON.md](SEASON.md). Точный текст первой серии: [story.json](story.json). Оригинальная озвучка и метки слов: [audio/](audio/).

## Редактирование

В папке `project/` находится проект Remotion. После установки Node.js:

```sh
npm install
npx remotion studio src/index.ts
```

Выберите композицию `Episode01-Dom17`. Четыре акта зарегистрированы как отдельные композиции для редактирования. Каждый из 16 эпизодов имеет собственную строку таймлайна.

Экспорт:

```sh
npx remotion render src/index.ts Episode01-Dom17 output/episode-01.mp4 --codec=h264 --video-bitrate=5M --audio-bitrate=192k
```

`src/episode/data.json` хранит продолжительность сцен и метки субтитров, `Shot.tsx` — визуальные компоненты, `ActOne.tsx`–`ActFour.tsx` — монтаж актов.
